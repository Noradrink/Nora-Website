# NORA — Drink to Glow

The marketing site and storefront for **NORA**, a sparkling beauty beverage
(collagen + vitamin C + electrolytes) in two flavors, Strawberry Pearl and
Lemon Elderflower, plus a Variety Pack. Checkout is powered by the Shopify
Storefront API: the cart lives on the site and checkout redirects to Shopify's
hosted checkout.

## Tech stack

- Vite 5 + React 18 + TypeScript 5
- Tailwind CSS v3 with a soft-luxury / editorial design system
- React Router v6, TanStack Query, Zustand (persisted cart)
- Shopify Storefront API (`2025-07`)

## Getting started

```bash
npm install
npm run dev      # http://localhost:8080
```

Other scripts:

```bash
npm run build    # type-check + production build to /dist
npm run preview  # preview the production build locally
```

## Shopify configuration

The store domain and Storefront token live in `src/lib/shopify.ts` with sensible
defaults already filled in. To override them (recommended for production),
create a `.env` file:

```
VITE_SHOPIFY_DOMAIN=nora-1312224.myshopify.com
VITE_SHOPIFY_STOREFRONT_TOKEN=your-storefront-token
```

The Storefront access token is a public, client-side token by design, so it is
safe to expose in the browser.

### Product handles expected in Shopify

The site merges Shopify pricing/inventory with editorial content by product
**handle**. Six products are expected, each with a single default variant:

| Product | 6-pack handle | 12-pack handle |
| --- | --- | --- |
| Strawberry Pearl | `strawberry-pearl` | `strawberry-pearl-12-pack` |
| Lemon Elderflower | `lemon-elderflower` | `lemon-elderflower-12-pack` |
| Variety Pack | `variety-pack-6-pack` | `variety-pack` |

If a handle does not exist in Shopify, that pack simply shows as unavailable.
Adjust the handles in `src/lib/products.ts` if your Shopify setup differs.

## Brand assets

The images in `src/assets/` are branded **placeholders** generated by
`scripts/generate-assets.mjs`. Replace them with the real product photography
(keep the same filenames) and they flow through the whole site automatically:

- `strawberry-pearl.png`, `lemon-elderflower.png` — single cans, transparent bg
- `nora-cans-blend.png` — both cans together
- `hero-duo.png` — wide hero banner
- `lifestyle-strawberry.jpg`, `lifestyle-lemon.jpg` — ritual cards

## Deploying

This is a static Vite build. Any static host works (Vercel, Netlify, Cloudflare
Pages, etc.). Build command `npm run build`, output directory `dist`. Make sure
the host is configured for single-page-app routing (all paths fall back to
`index.html`).
